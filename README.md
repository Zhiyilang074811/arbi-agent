# ArbiAgent — AI Trading Agent for Arbitrum

AI-powered autonomous trading agent built on Arbitrum with x402 micropayment integration.

## Features
- AI-driven market analysis on Arbitrum One
- x402 protocol for micro-settlement of trading strategies
- Real-time P&L tracking and portfolio management
- Support for ARB, ETH, USDC pairs
- CMC API integration for market data
- Gas-optimized L2 execution

## Tech Stack
- React 18 + Vite 5
- Tailwind CSS
- Arbitrum RPC
- CMC API
- x402 Payments
- Viem/Wagmi
